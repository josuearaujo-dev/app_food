Popup Combos com Add e seção única v2.7.0
=========================================

O popup de ofertas especiais passa a se chamar Combos
e ganha botão Add em cada card.
A seção antiga de Combos some do cardápio.
A seção Special offers vira Combos e fica a única lista desses itens.
No admin, a lista de seções acompanha isso.

Como aplicar
------------
1) Copiar TODOS os arquivos desta pasta mantendo o mesmo caminho.
   Não deixe a pasta deploy-altered-v2.7.0 dentro do repositório.
2) Nenhum SQL novo. O script 047 do pacote v2.6.0 continua valendo.
   Neste banco (kujvnoscdmdarwmoivtq) ele já foi aplicado.
3) Commit + push no GitHub / deploy (Vercel).
4) Este pacote vem DEPOIS do v2.6.0. Aplique os dois.

------------------
- app/admin/cardapio/page.tsx

- components/home-promo-carousel.module.css

Obs.
----
No popup, Add fecha as ofertas e abre o popup do combo
quando há escolha ou opções. Sem escolha, adiciona direto.
A ordem padrão das seções fica: Mais pedidos, Combos, Destaques.
O .env.local NÃO entra neste pacote.
