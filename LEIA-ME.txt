Logs + fallback Add dos combos v2.9.1
=====================================

Em https://www.caducakeslanches.store /api/banners ainda devolve
href: null. Por isso o Add não fazia nada.

Este pacote:
1) Corrige /api/banners para devolver /combo/{id}
2) Se o href vier null, resolve o combo pelo nome (lista local
   ou consulta no Supabase)
3) Coloca logs no console do navegador e no server da Vercel
   com o prefixo [cadu:combo-add]

Como aplicar
------------
1) Copiar TODOS os arquivos desta pasta mantendo o mesmo caminho.
2) Commit + push / redeploy Vercel.
3) Abrir o site, F12 > Console, clicar Add no popup Combos.
4) Procurar linhas [cadu:combo-add].

Arquivos
--------
- app/api/banners/route.ts
- app/combo/[id]/page.tsx
- components/home-promo-carousel.tsx
- components/home-promo-carousel.module.css
- components/storefront/combo-customize-modal.tsx
- components/storefront/store-image.tsx

Como ler os logs
----------------
No Console do navegador:
- banners loaded  -> o que a API mandou (href null ou não)
- combos ready    -> quantos combos o app carregou
- Add clicked     -> clique no botão
- resolved href   -> achou o combo pelo nome
- openCombo       -> abriu o modal
- abort           -> não achou combo nenhum

Na Vercel (Functions / Runtime Logs):
- [cadu:combo-add] /api/banners

Confirme também em /api/banners se href deixou de ser null.
O .env.local NÃO entra neste pacote.
