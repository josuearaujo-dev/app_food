Página de manutenção v1.6.0
===========================

A página inicial (/) passa a mostrar um aviso em inglês enquanto a loja
está em ajuste. Admin, cardápio interno e demais rotas continuam no projeto.

Como aplicar
------------
1) Copiar TODOS os arquivos desta pasta mantendo o mesmo caminho.
2) Commit + push no GitHub / deploy (Vercel etc.).

Arquivos NOVOS
--------------
- components/storefront/store-maintenance.tsx
- lib/store-maintenance.ts

Arquivos ALTERADOS
------------------
- app/page.tsx
- lib/layout/page-chrome.ts
- styles/storefront.css

Reabrir a loja
--------------
Em lib/store-maintenance.ts, mude:
  export const STOREFRONT_MAINTENANCE = true
para:
  export const STOREFRONT_MAINTENANCE = false
