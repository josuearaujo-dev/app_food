Descrição no banner de ofertas v2.1.0
=====================================

O cartão da oferta mostra a descrição do banner.
Se o banner não tiver texto, usa a descrição do produto ou do combo.

Como aplicar
------------
1) Copiar TODOS os arquivos desta pasta mantendo o mesmo caminho.
   Não deixe a pasta deploy-altered-v2.1.0 dentro do repositório.
2) Rodar scripts/042_banners_descricao.sql no Supabase (uma vez).
   Neste banco (kujvnoscdmdarwmoivtq) as colunas já foram criadas.
3) Commit + push no GitHub / deploy (Vercel).
4) Este pacote vem DEPOIS do v2.0.0. Aplique os dois.

- scripts/042_banners_descricao.sql
