Marketing pixels / funil de compra v1.5.0
=========================================

O que esta versão adiciona
--------------------------
- Tela Admin → Marketing (depois de Operações)
- Instalação real de GTM, Meta Pixel, GA4, Google Ads e TikTok no cardápio
- Funil: PageView → ViewContent → AddToCart → InitiateCheckout → AddPaymentInfo → Purchase
- Meta CAPI + TikTok Events API no servidor (tokens NÃO vão ao navegador)
- Consentimento opcional no cardápio (desligado por padrão = pixel entra na hora)

Como aplicar no projeto
-----------------------
1) Copiar TODOS os arquivos desta pasta mantendo o mesmo caminho no projeto.
2) Rodar no Supabase o SQL:
     scripts/039_store_marketing_settings.sql
3) Commit + push no GitHub / deploy (Vercel etc.).
4) No admin: Marketing → colar o Meta Pixel ID → Salvar.
5) Abrir o cardápio com Meta Pixel Helper — deve aparecer fbq + PageView.
