Corrige Add dos combos no popup/menu v2.8.0
===========================================

No servidor o botão Add dos combos não abria o popup de montagem
porque o pacote v2.7.0 subiu o storefront sem os arquivos do modal.

Este pacote traz TUDO que o Add precisa:
- modal do combo
- página/componente ComboCustomize
- home + carousel com botão Add
- seção Combos (sem a seção antiga duplicada)
- SQL das seções de escolha

Como aplicar
------------
1) Copiar TODOS os arquivos desta pasta mantendo o mesmo caminho.
   Não deixe a pasta deploy-altered-v2.8.0 dentro do repositório.
2) Rodar no Supabase, se ainda não rodou:
   - scripts/047_combo_escolha.sql
   Sem essas tabelas, a seção de escolha do combo quebra.
3) Commit + push no GitHub / deploy (Vercel).
4) Pode aplicar este pacote sozinho em cima do site atual.
   Ele substitui o que faltava no v2.6/v2.7.
