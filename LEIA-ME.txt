Mais pedidos pelas vendas reais v2.13.0
======================================

A seção "Mais pedidos" / "Most ordered" usa as vendas reais
(pedido_itens), top 6 produtos disponíveis.

Por que não aparecia
--------------------
A rota /api/most-ordered não estava no site publicado (404).
Sem essa API, o menu não recebia os IDs e escondia a seção.
No banco já há vendas suficientes para montar o ranking.

Como aplicar
------------
1) Copiar TODOS os arquivos desta pasta mantendo o mesmo caminho.
   Não deixe a pasta deploy-altered-v2.13.0 dentro do repositório.
2) Nenhum SQL novo.
3) Commit + push / redeploy Vercel.
4) Hard refresh (Cmd+Shift+R).
5) Confira: https://SEU-DOMINIO/api/most-ordered
   deve responder JSON com "ids": [ ... ] (não 404).
