Seções na lista de categorias v2.5.0
=====================================

Special offers deixa de ser o botão que abre o popup e vira uma seção
do cardápio, junto com Mais pedidos, Combos e Destaques.
Essas seções entram na lista de categorias do admin para escolher a posição.
A mesma ordem aparece nos filtros do cardápio.

Como aplicar
------------
1) Copiar TODOS os arquivos desta pasta mantendo o mesmo caminho.
   Não deixe a pasta deploy-altered-v2.5.0 dentro do repositório.
2) Rodar no Supabase, uma vez:
   - scripts/046_cardapio_ordem.sql
   Neste banco (kujvnoscdmdarwmoivtq) a tabela já foi criada.
3) Commit + push no GitHub / deploy (Vercel).
4) Este pacote vem DEPOIS do v2.4.0. Aplique os dois.

Arquivos NOVOS
--------------
- lib/menu-layout.ts
- scripts/046_cardapio_ordem.sql

Arquivos ALTERADOS
------------------
- app/admin/cardapio/page.tsx
- components/home-promo-carousel.tsx
- components/home-promo-carousel.module.css
- components/storefront/storefront-home.tsx
- lib/lang-context.tsx

Obs.
----
Até alguém mover a lista, a ordem é: Mais pedidos, Combos,
Special offers, Destaques e depois as categorias de comida.
No admin, as seções só podem ser movidas. Categorias continuam
podendo ser editadas e excluídas.
O .env.local NÃO entra neste pacote.
