Banners e Ofertas como popups v2.14.1
=====================================

Correção
--------
- Banner volta a ser POPUP (carousel), não fica no menu.
- Ordem na entrada: 1º popup de banners → ao fechar → 2º popup
  de Ofertas especiais.
- Ofertas especiais continuam na seção do menu também.
- Se o SQL 048 ainda não rodou, as ofertas usam os destinos
  dos banners como fallback (para o popup não ficar vazio).

Como aplicar
------------
1) Rodar no Supabase SQL Editor (recomendado):
   scripts/048_oferta_especial.sql
2) Copiar TODOS os arquivos desta pasta mantendo o caminho.
3) Redeploy Vercel + hard refresh.
