Loja fechada / fim da manutenção v1.7.0
=========================================

A página de manutenção saiu. O cardápio volta, e a loja fica fechada
para novos pedidos até alguém reabrir no admin.

Como aplicar
------------
1) Copiar TODOS os arquivos desta pasta mantendo o mesmo caminho.
2) APAGAR estes arquivos, se ainda existirem no projeto:
     components/storefront/store-maintenance.tsx
     lib/store-maintenance.ts
3) O SQL scripts/040_loja_aceitando_pedidos.sql JÁ foi executado
   no projeto novo Cadu Cakes (conta josuearaujo-9422).
   Se for outro banco, rode esse SQL antes do deploy.
4) Commit + push no GitHub / deploy (Vercel).

No admin
--------
Operações → botão "Loja fechada" / "Aceitando pedidos".
Com a loja fechada, o cliente vê o cardápio e não consegue finalizar pedido.
Pedido manual do painel continua funcionando.
